## Features

- Rolls the digits up when you count up and down when you count down, with
  NumberFlow.
- Plays a click and a selection haptic on every step, throttled so a fast hold
  never stacks sounds.
- Repeats when held, speeds up over the first second and a half, and moves ten
  steps at a time after ten repeats.
- Nudges the value with a pop and a rigid haptic when it hits `min` or `max`,
  and fades out the button that can't go further.
- Takes typed and pasted values, then clamps and snaps them to `step` on
  commit, with a warning cue when it had to correct them.
- Formats currency, percent, and units through `Intl.NumberFormat`, and comes
  in `outline`, `pill`, and `ghost` variants with a vertical orientation.

## Usage

```tsx
import { NumberStepper } from "@/components/number-stepper";
```

```tsx
<NumberStepper label="Guests" variant="pill" defaultValue={2} min={1} max={12} />
```

Use `value` and `onValueChange` to control it. `onValueChange` fires on every
step; `onValueCommit` fires once a press is released, a typed value is
committed, or a key steps. Changes that come from the `value` prop stay silent,
and a new `value` from outside stops a hold in progress.

```tsx
const [seats, setSeats] = useState(1);

<NumberStepper
  label="Seats"
  value={seats}
  onValueChange={setSeats}
  min={1}
  max={8}
/>
```

Pass `format` for currency, percent, or units. Percent values are fractions,
so typing `15` into the field below means `0.15`.

```tsx
<NumberStepper
  label="Tip"
  defaultValue={0.15}
  max={0.3}
  step={0.05}
  format={{ style: "percent" }}
/>

<NumberStepper
  label="Budget"
  defaultValue={40}
  step={5}
  format={{ style: "currency", currency: "EUR" }}
  locale="de-DE"
/>
```

Set `orientation="vertical"` to put the increase button above the value, and
`size` to `sm`, `md`, or `lg`. Give it a `name` to submit the value with a
native form, and set `wheel` to let the scroll wheel change a focused field.

## Accessibility

The input is a `spinbutton` with `aria-valuenow`, `aria-valuemin`,
`aria-valuemax`, and an `aria-valuetext` built from `format`. Name it with
`label`. The buttons read "Increase" and "Decrease" followed by the label, and
are left out of the tab order so `Tab` goes straight to the input.

Arrow keys move one step, `Shift` with an arrow or `PageUp`/`PageDown` move
`largeStep` steps, `Home`/`End` jump to the limits, `Enter` commits a typed
value, and `Escape` reverts it. Changes made with the buttons are announced
through a polite live region once the value settles, so a hold doesn't chatter.

With reduced motion enabled the digits change without rolling, and there is no
nudge or pulsing ring. Sound and haptics stay on because they confirm each step
rather than decorate movement; turn them off with `sound={false}` and
`haptics={false}`.

## FAQ

### How do I install the Number Stepper with shadcn?

Run `npx shadcn@latest add @tentui/number-stepper` after adding the `@tentui`
registry to `components.json` ([installation guide](/docs/installation)), or run
`npx shadcn@latest add https://tentui.com/r/number-stepper.json` without it. The
CLI copies `number-stepper.tsx` into your project and installs
`@number-flow/react`, `motion`, `lucide-react`, `web-haptics`, and
`@rexa-developer/tiks`.

### Can the Number Stepper format currency, percent, or units?

Yes. Pass `Intl.NumberFormat` options to `format`, such as
`format={{ style: "currency", currency: "EUR" }}`, and set `locale` to control
formatting and how typed values are parsed. Percent values are fractions, so
`0.15` displays as 15%.

### Is the Number Stepper accessible?

Yes. The input is a `spinbutton` named by `label`, with `aria-valuetext` built
from `format`. Arrow keys step, `Shift` with an arrow or `PageUp`/`PageDown`
moves `largeStep` steps, `Home` and `End` jump to the limits, and button changes
are announced through a polite live region once the value settles.

### How do I use it as a controlled input or in a form?

Pass `value` and `onValueChange`; with React Hook Form, pass `field.value` and
`field.onChange` from a `Controller`. Set `name` to submit the value with a
native form through a hidden input, and use `onValueCommit` to save once a press
is released or a typed value is committed.

### What happens when I hold the increase button?

The value keeps stepping while you hold it. With `accelerate` on (the default),
after 10 repeats each step moves `largeStep` steps (10 by default), and the
value stops at `min` and `max` with a pop, a haptic, and a small nudge.

source into your project, and you can use it in unlimited personal and client
