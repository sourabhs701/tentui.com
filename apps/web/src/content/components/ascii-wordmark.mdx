ASCII Wordmark samples any word into a GPU particle texture, moves those particles
through a simplex-noise flow field, and converts the rendered result into a live
grid of ASCII glyphs. Fine pointers repel nearby particles and paint a short color
trail through the grid.

## Features

- Simulates up to 40,000 particles with Three.js `GPUComputationRenderer`.
- Rebuilds the particle target from any word and accepts a custom ink color.
- Repels particles and colors nearby glyphs in direct response to the pointer.
- Pauses outside the viewport or while the page is hidden.
- Reduces particle density on coarse pointers and renders a static wordmark when reduced motion is requested.

## Usage

```tsx
import { AsciiWordmark } from "@/components/ascii-wordmark/ascii-wordmark";
```

```tsx
<div className="bg-neutral-950">
  <AsciiWordmark word="VAULT" inkColor="#8b80ff" />
</div>
```

The component supplies a responsive `16 / 5` aspect ratio and a minimum height.
Pass a `className` when the surrounding layout should control its dimensions.

## Accessibility

The canvas is hidden from assistive technology and the host is exposed as an
image labeled with the rendered word. Override `aria-label` when the word needs
more context. Reduced-motion users receive the assembled word without the
continuous flow-field simulation or cursor effects.
