## Example

<ComponentPreview name="tile-field-demo" canConfigure />

Tile Field turns a text wordmark into a responsive canvas of square tiles. A
slow customizable color wave moves through the letters while fine-pointer
movement brushes a soft light across nearby tiles and occasionally reveals
small sparks. Use the preview controls to change the text and color.

## Features

- Fits any wordmark to the available width and rebuilds the grid when its container resizes.
- Adapts its resting tiles to light and dark themes.
- Accepts any CSS color for the wave, pointer glow, and sparks.
- Includes DialKit preview controls for editing the text and color live.
- Batches tile drawing with `Path2D` and caps canvas density at `2x` device pixel ratio.
- Pushes and drifts individual tiles around the cursor with a slowly fading light trail.
- Pauses while off-screen or while the document is hidden.
- Ignores touch input and renders a static fallback for reduced-motion preferences.
- Uses no animation dependency.

## Usage

```tsx
import { TileField } from "@/components/tile-field";
```

```tsx
<TileField
  word="humandelta <3"
  color="#6366f1"
  className="min-h-64 rounded-xl bg-background"
/>
```

The component includes a `min-height` so it works without setup. Pass a height,
minimum height, or aspect ratio through `className` to fit your layout. Its
resting tiles inherit `text-muted-foreground`, so they update with your theme.

## Accessibility

The generated canvas is hidden from assistive technology. Its host exposes the
word as an image label by default; pass `aria-label` when the visible word needs
more descriptive alternative text. Touch input does not activate the cursor
light, and reduced-motion users receive a static tile wordmark.

## FAQ

### How do I install the Tile Field Wordmark with shadcn?

Run `npx shadcn@latest add @tentui/tile-field` after adding the `@tentui`
registry to `components.json` ([installation guide](/docs/installation)), or run
`npx shadcn@latest add https://tentui.com/r/tile-field.json` without it. The CLI
copies `tile-field.tsx` into your project; it draws on a canvas and needs no
other packages.

### How do I change the word and colors?

Set `word` (it defaults to "Localhost") and `color`, which accepts any CSS
color and drives the wave, pointer glow, and sparks. The resting tiles use the
element's text color, `text-muted-foreground` by default, so pass another
`text-*` class to change them.

### How do I size the Tile Field?

It fills the container's width with a 12rem minimum height, and the word scales
to the width. Set a height, minimum height, or aspect ratio through `className`;
the tile grid rebuilds whenever the element resizes.

### Will it slow down my page?

It is built to stay light: it pauses while off-screen or in a hidden tab, caps
the canvas at 2x device pixel ratio, and draws the tiles in batches. With
reduced motion enabled it draws a static wordmark, and touch input doesn't start
the pointer light.

### Is the wordmark readable by screen readers and search engines?

Screen readers announce it as an image labeled with the word, or with your
`aria-label`, and the canvas itself is hidden. Because the letters are pixels
rather than text, keep a real heading on the page if the word is its title.

### Is the Tile Field Wordmark free to use?

Yes. The Tile Field Wordmark is free and source-available: the shadcn CLI
copies its source into your project, and you can use it in unlimited personal
and client projects under the [TentUI License](/license). The license doesn't
allow redistributing or reselling the component itself.
