Realistic Emboss turns text or raw SVG markup into a height field, then lights its
beveled edges against a procedural plaster surface. It renders only when content,
size, or visual parameters change, so the effect stays still and inexpensive after
the first frame.

## Features

- Accepts text or a custom SVG logo through a small prop API.
- Generates plaster grain in the shader with no image requests or texture files.
- Rebuilds its height field responsively with a capped raster size.
- Exposes depth, bevel, light, surface, and content placement controls.
- Keeps the surface visible as a color fallback when WebGL is unavailable.

## Usage

```tsx
import { RealisticEmboss } from "@/components/realistic-emboss";
```

Use text for a quick wordmark.

```tsx
<RealisticEmboss
  aria-label="Studio wordmark embossed into plaster"
  className="aspect-video rounded-3xl"
  color="#cbb99f"
  text="STUDIO"
/>
```

Pass raw SVG markup for custom logos. The component converts the artwork to a
single silhouette before building the bevel, so bold filled shapes read best.

```tsx
const logo = `<svg viewBox="0 0 200 80">...</svg>`;

<RealisticEmboss
  aria-label="Acme logo embossed into plaster"
  className="aspect-video rounded-3xl"
  contentScale={0.32}
  depth={1.3}
  svg={logo}
/>
```

## Accessibility

Provide an `aria-label` when the pressed content communicates information. Without
one, the component marks its canvas surface as decorative. The canvas does not
capture pointer input and the effect has no continuous or entrance animation.
