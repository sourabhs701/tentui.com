## Features

- Copies the primary mark or logotype as raw SVG markup with sound, haptic, and inline icon feedback.
- Keeps the menu open after copying so the row can confirm the result.
- Keeps the menu compact with three focused actions.
- Downloads the complete SVG and PNG brand kit as a ZIP archive.

## Brand asset hosting

The default TentUI SVGs and downloadable archive are served from
`https://cdn.tentui.com/brand/`. Use `markAsset`, `logotypeAsset`, and
`brandAssetsZipPath` to point the component at your own hosted assets.

## Usage

```tsx
import { BrandContextMenu } from "@/components/brand-context-menu";
```

```tsx
<BrandContextMenu>
  <button type="button">Right-click for brand assets</button>
</BrandContextMenu>
```

Pass custom mark and logotype assets and point the component to your archive.

```tsx
const mark = {
  name: "Mark",
  path: "https://cdn.example.com/brand/mark.svg",
  filename: "acme-mark.svg",
};

const logotype = {
  name: "Logotype",
  path: "https://cdn.example.com/brand/logotype.svg",
  filename: "acme-logotype.svg",
};

<BrandContextMenu
  markAsset={mark}
  logotypeAsset={logotype}
  brandAssetsZipPath="https://cdn.example.com/brand/acme-brand-assets.zip"
>
  <button type="button">Open brand kit</button>
</BrandContextMenu>;
```

## FAQ

### How do I install the Brand Context Menu with shadcn?

Run `npx shadcn@latest add @tentui/brand-context-menu` after adding the
`@tentui` registry to `components.json`
([installation guide](/docs/installation)), or run
`npx shadcn@latest add https://tentui.com/r/brand-context-menu.json` without
it. The CLI copies `brand-context-menu.tsx` into your project, installs
`lucide-react`, and adds the shadcn `context-menu` and TentUI
[Copy Button](/components/copy-button) it builds on.

### How do I use my own logo and brand kit?

Pass `markAsset` and `logotypeAsset`, each with a `name`, a `path` to the SVG,
and a `filename`, and set `brandAssetsZipPath` to your archive. Without them the
menu serves TentUI's own assets from `cdn.tentui.com`.

### Why does "Copy Mark as SVG" show "Copy failed"?

The menu fetches the SVG and copies its markup, so the copy fails if that
request fails. Host the SVG on the same origin or serve it with CORS headers
that allow your site; clipboard access also needs a secure context such as
HTTPS or `localhost`.

### Does it work with Radix-based shadcn/ui components?

It is written for shadcn/ui's Base UI components: the trigger uses the `render`
prop and the copy rows use `closeOnClick={false}` to stay open after copying.
With a Radix-based `context-menu`, use `asChild` on the trigger and call
`event.preventDefault()` in the copy rows' `onSelect` instead.

### What can I right-click to open the menu?

Any single React element passed as `children`, such as the logo link in your
header. The menu opens on that element's context menu event, so the rest of the
page keeps the browser's default menu.

### Is the Brand Context Menu free to use?

Yes. The Brand Context Menu is free and source-available: the shadcn CLI copies
its source into your project, and you can use it in unlimited personal and
client projects under the [TentUI License](/license). The license doesn't allow
redistributing or reselling the component itself.
