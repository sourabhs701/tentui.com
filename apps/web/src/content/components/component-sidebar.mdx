## Features

- Expands guide lines as the pointer approaches, keeping dense navigation easy to scan.
- Supports controlled and uncontrolled open state with an optional single-key shortcut.
- Accepts a custom link renderer for Next.js, React Router, or other routing libraries.
- Scrolls the active item into view and marks it with `aria-current="page"`.
- Shows accessible blue markers for new items and yellow markers for updated items.
- Ignores touch pointers and removes movement for reduced-motion users.
- Plays a soft scan tick, uses a metal click when opening or closing, and pairs navigation with click sounds and selection haptics.
- Exposes interaction callbacks for application-specific behavior.

## Usage

```tsx
import {
  ComponentSidebar,
  ComponentSidebarContent,
} from "@/components/component-sidebar";
```

```tsx
const groups = [
  {
    title: "Getting started",
    items: [
      { title: "Overview", href: "/overview" },
      { title: "Installation", href: "/installation" },
    ],
  },
  {
    title: "Components",
    newCount: 1,
    items: [
      { title: "Button", href: "/button", isUpdated: true },
      { title: "Dialog", href: "/dialog", isNew: true },
    ],
  },
];

<ComponentSidebar>
  <ComponentSidebarContent
    activeHref="/overview"
    groups={groups}
  />
</ComponentSidebar>
```

### Framework links

Use `renderLink` to preserve client-side navigation. The component supplies the active ref, accessibility attributes, external-link attributes, feedback handlers, and children, so spread all supplied props.

```tsx
import type { Route } from "next";
import Link from "next/link";

function renderLink({ href, ...props }) {
  return <Link href={href as Route} {...props} />;
}

<ComponentSidebarContent
  activeHref={pathname}
  groups={groups}
  renderLink={renderLink}
/>
```

### Layout

Override the component's CSS variables with utilities when it needs to fit a specific shell.

```tsx
<ComponentSidebar className="[--component-sidebar-height:calc(100svh-4rem)] [--component-sidebar-top:4rem] [--component-sidebar-width:16rem]">
  {/* Navigation */}
</ComponentSidebar>
```

## Accessibility

The toggle has an accessible name, exposes its expanded state, and points to the controlled panel. Closed content is inert, active links use `aria-current`, and the default `S` shortcut is ignored while typing in editable controls. Set `shortcutKey={false}` when a single-key shortcut is not appropriate.

## FAQ

### How do I install the Component Sidebar with shadcn?

Run `npx shadcn@latest add @tentui/component-sidebar` after adding the
`@tentui` registry to `components.json`
([installation guide](/docs/installation)), or run
`npx shadcn@latest add https://tentui.com/r/component-sidebar.json` without
it. The CLI copies the sidebar and its click sound into your project, adds the
shadcn `badge`, `button`, `kbd`, and `tooltip` components, and installs
`motion`, `web-haptics`, and `@rexa-developer/tiks`; wrap your app in
`TooltipProvider` if it isn't already.

### How do I use the Component Sidebar with Next.js Link?

Pass `renderLink` and spread every prop it receives onto your router's link,
for example `({ href, ...props }) => <Link href={href} {...props} />`. Those
props carry the ref, `aria-current`, click feedback, and external-link
attributes, and links default to a plain `a` element.

### Can I control whether the sidebar is open?

Yes. Pass `open` and `onOpenChange` to control it, or `defaultOpen`, which is
`true`, to let it manage itself. The `S` key toggles it unless the user is
typing in a field or holding a modifier key; change it with `shortcutKey` or
pass `false` to remove it.

### Is the Component Sidebar accessible?

Yes. The toggle has an accessible name and exposes `aria-expanded` and
`aria-controls`, the closed panel is `inert`, and the active link gets
`aria-current="page"` and scrolls into view. New and updated markers include
screen-reader text, and the proximity effect ignores touch and turns off with
reduced motion.

### How do I change the sidebar's width, height, or position?

Override its CSS variables from `className`: for example,
`[--component-sidebar-width:16rem]`, `[--component-sidebar-top:4rem]` for a
sticky offset below a header, and
`[--component-sidebar-height:calc(100svh-4rem)]`. Use `panelClassName` to
restyle the bordered panel.

### Is the Component Sidebar free to use?

Yes. The Component Sidebar is free and source-available: the shadcn CLI copies
its source into your project, and you can use it in unlimited personal and
client projects under the [TentUI License](/license). The license doesn't allow
redistributing or reselling the component itself.
