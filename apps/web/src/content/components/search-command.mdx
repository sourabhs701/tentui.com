## Features

- Matches the compact search command used in the TentUI navigation bar.
- Opens with `Mod+K` or `/` and displays the correct Command or Control key for the user's platform.
- Groups pages, actions, and settings with icons, searchable descriptions, metadata, disabled states, and hotkey hints.
- Supports controlled and uncontrolled dialog state.
- Keeps routing framework-agnostic through item and global selection callbacks.
- Ignores slash shortcuts while the user is typing in an input, select, textarea, or editable region.
- Updates the footer action as keyboard or pointer selection moves between groups.

## Usage

```tsx
import { SearchCommand } from "@/components/search-command";
```

```tsx
const groups = [
  {
    heading: "Menu",
    actionLabel: "Go to page",
    items: [
      {
        title: "Home",
        description: "Workspace overview",
        keywords: ["dashboard"],
        shortcut: "GH",
      },
      {
        title: "Settings",
        description: "Preferences and integrations",
        shortcut: "GS",
      },
    ],
  },
];

<SearchCommand
  groups={groups}
  onItemSelect={(item) => console.log(item.title)}
/>
```

### Routing

Keep navigation in the application layer so the component works with Next.js, React Router, TanStack Router, or regular browser navigation.

```tsx
const router = useRouter();

const groups = [
  {
    heading: "Pages",
    items: [
      { title: "Home", value: "/" },
      { title: "Customers", value: "/customers" },
    ],
  },
];

<SearchCommand
  groups={groups}
  onItemSelect={(item) => router.push(item.value ?? "/")}
/>
```

### Actions

Add `onSelect` to an item when it owns an action. Both the item callback and `onItemSelect` run after the menu closes.

```tsx
{
  title: "Create document",
  keywords: ["new", "page"],
  onSelect: createDocument,
}
```

### Settings

Settings use the same item API as pages and actions. For example, add an appearance group with `next-themes`.

```tsx
const { setTheme } = useTheme();

const themeGroup = {
  heading: "Theme",
  actionLabel: "Change theme",
  items: [
    {
      title: "Light",
      icon: <SunMediumIcon />,
      onSelect: () => setTheme("light"),
    },
    {
      title: "Dark",
      icon: <MoonStarIcon />,
      onSelect: () => setTheme("dark"),
    },
    {
      title: "System",
      icon: <MonitorIcon />,
      onSelect: () => setTheme("system"),
    },
  ],
};

<SearchCommand groups={[...groups, themeGroup]} />
```

Pass `enabledHotkeys={false}` if another command palette already owns `Mod+K` and `/` on the page. The shortcut keys remain visible in the trigger.

## Accessibility

The trigger exposes its dialog state and `Meta+K`, `Control+K`, and `/` shortcuts. The dialog has a configurable title and description for assistive technology, all items live inside command groups, and slash is ignored while the user is editing text.

## FAQ

### How do I install the Search Command with shadcn?

Run `npx shadcn@latest add @tentui/search-command` after adding the `@tentui`
registry to `components.json` ([installation guide](/docs/installation)), or run
`npx shadcn@latest add https://tentui.com/r/search-command.json` without it.
The CLI copies `search-command.tsx` into your project, installs `lucide-react`
and `react-hotkeys-hook`, and adds the shadcn `button`, `command`, and `kbd`
components.

### Why doesn't Cmd+K open the Search Command?

The shortcuts are off by default, so pass `enabledHotkeys` to turn on `Mod+K`
and `/`, and set `shortcutKey` to use another letter. To open it from your own
code instead, control it with `open` and `onOpenChange`.

### Why does the trigger show Ctrl instead of ⌘ on a Mac?

With `shortcutModifier="auto"`, the ⌘ hint only shows when an ancestor such as
`<html>` has the `os-macos` class, which TentUI's site adds with a small inline
script. Add that class on macOS yourself, or set `shortcutModifier` to
`"command"` or `"control"` to pick one.

### How do I navigate with the Next.js router or React Router?

Give each item a `value` such as its path and call your router in
`onItemSelect`, for example `router.push(item.value)`. Items can also run their
own `onSelect`, and both callbacks run after the dialog closes.

### Is the Search Command keyboard accessible?

Yes. It is built on the shadcn `command` component (cmdk) inside a dialog, so
arrow keys move through results, `Enter` runs the highlighted one, and `Escape`
closes it. The trigger exposes `aria-expanded` and `aria-keyshortcuts`, and the
dialog's `title` and `description` are available to screen readers.

### Is the Search Command free to use?

Yes. The Search Command is free and source-available: the shadcn CLI copies its
source into your project, and you can use it in unlimited personal and client
projects under the [TentUI License](/license). The license doesn't allow
redistributing or reselling the component itself.
