## Features

- Includes eight responsive Tailwind CSS button styles.
- Copies complete JSX snippets directly to the clipboard.
- Provides animated success and error feedback with `CopyButton`.
- Generates previews and copied JSX from the same button functions.
- Uses standalone utility classes without a custom Tailwind configuration.

## Accessibility

Each example renders a native `button` with keyboard focus styles. The copy
controls have visible labels and display distinct success and error states.
