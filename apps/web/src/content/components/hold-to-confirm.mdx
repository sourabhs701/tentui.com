## Features

- Sweeps a destructive fill across the button while it is held, with the label
  redrawn on the fill so it stays readable.
- Plays a tone that rises in pitch with progress and resolves into a chime on
  confirm.
- Ticks haptics at each tenth of the hold, a little stronger each time, and
  finishes with a success pattern on supported devices.
- Springs the fill back when released early, and resumes from where it is if
  pressed again mid-spring.
- Ends with a drawn checkmark, then resets after a configurable delay.
- Works with pointer, touch, and keyboard (hold `Space` or
  `Enter`).

## Usage

```tsx
import { HoldToConfirm } from "@/components/hold-to-confirm";
```

```tsx
<HoldToConfirm onConfirm={() => deleteProject(project.id)} />
```

Customize the labels, timing, and fill color.

```tsx
<HoldToConfirm
  icon={<LogOutIcon />}
  confirmedLabel="Signed out"
  holdDuration={1200}
  fillClassName="bg-amber-500 text-black"
>
  Hold to sign out
</HoldToConfirm>
```

Pass `resetDelay={false}` to keep the button confirmed, for example while the
deletion request is in flight or before navigating away.

```tsx
<HoldToConfirm resetDelay={false} onConfirm={handleDelete} />
```

### Hook

Use `useHoldToConfirm` to build your own surface. It returns the hold `state`,
a `progress` motion value from `0` to `1`, the event `handlers` to spread on a
button, and a `reset` function.

```tsx
const { state, progress, handlers } = useHoldToConfirm({
  onConfirm: handleDelete,
});
```

## Accessibility

The button keeps native focus behavior and is held from the keyboard with
`Space` or `Enter`; releasing the key or moving focus away
cancels the hold. The `instructions` prop is linked through
`aria-describedby`, and the confirmed label is announced through a polite live
region.

With reduced motion enabled, the press scale and spring-back are replaced by a
short fade, and sound is muted to match the rest of TentUI. The fill and
checkmark remain because they communicate the state.

## FAQ

### How do I install the Hold to Confirm button with shadcn?

Run `npx shadcn@latest add @tentui/hold-to-confirm` after adding the `@tentui`
registry to `components.json` ([installation guide](/docs/installation)), or run
`npx shadcn@latest add https://tentui.com/r/hold-to-confirm.json` without it.
The CLI copies `hold-to-confirm.tsx` and the `use-hold-to-confirm.ts` hook into
your project and installs `motion`, `lucide-react`, and `web-haptics`.

### How long does the user have to hold the button?

1.5 seconds by default; set `holdDuration` in milliseconds to change it.
Releasing early animates the fill back and calls `onCancel` with the progress
reached, and after confirming the button resets after 2 seconds, or stays
confirmed with `resetDelay={false}`.

### Is the Hold to Confirm button keyboard accessible?

Yes. It is a native button that is held with `Space` or `Enter`, and releasing
the key or moving focus away cancels the hold. The `instructions` text is linked
through `aria-describedby`, and the confirmed label is announced through a
polite live region.

### Can I change the label, icon, and color?

Yes. Pass the idle label as `children`, and set `icon`, `confirmedLabel`,
`confirmedIcon`, and `fillClassName`, for example
`fillClassName="bg-amber-500 text-black"`. For a fully custom surface, use the
`useHoldToConfirm` hook, which returns the hold state, a progress motion value,
and the event handlers.

### Can I turn off the sound and haptics?

Yes. Set `sound={false}` and `haptics={false}`. Sound is also muted when the
user prefers reduced motion.

### Is the Hold to Confirm button free to use?

Yes. The Hold to Confirm button is free and source-available: the shadcn CLI
copies its source into your project, and you can use it in unlimited personal
and client projects under the [TentUI License](/license). The license doesn't
allow redistributing or reselling the component itself.
