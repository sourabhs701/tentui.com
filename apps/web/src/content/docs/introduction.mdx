Tent UI is an open-source component registry built on top of [shadcn/ui](https://ui.shadcn.com). It focuses on purposeful, production-ready components for the details that make an interface feel considered: expressive interactions, motion, specialized controls, and domain-specific UI.

Every component arrives as editable source code. Install only what you need, adapt it to your product, and keep full ownership of the result.

## Get started

Follow the [installation guide](/docs/installation) to configure the Tent UI registry and add your first component with the shadcn CLI.

## Designed to complement your stack

Tent UI is not a replacement for your core component library. Keep using shadcn/ui, Base UI, Radix, or whichever foundation fits your product for common primitives such as forms, dialogs, and layout.

Reach for Tent UI when you need the more specific tool: an interaction with personality, a polished motion detail, or a component that would otherwise take hours to build well. Think of it as the specialist drawer in your frontend toolkit.

## Built for ownership

There is no runtime package or abstraction to work around. Components are installed directly into your codebase, so you can inspect every line, adjust every detail, and ship without adding a permanent dependency on Tent UI.

Browse the [component library](/components) to find your next building block, explore complete [blocks](/blocks), or connect the [MCP server](/docs/mcp) to discover and install components from your AI-enabled editor.
