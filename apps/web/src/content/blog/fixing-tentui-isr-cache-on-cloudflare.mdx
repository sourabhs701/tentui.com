## The failure

TentUI's GitHub star count is cached for one day. When that cache became stale, production requests started failing because the OpenNext setup could read build-time assets but could not write regenerated entries or coordinate revalidation.

## The fix

The site combined time-based revalidation with a read-only incremental cache and no production-ready queue. The fix was to use R2 as the writable incremental cache and an OpenNext Durable Object queue to coordinate regeneration.
